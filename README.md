# VM Weather App

A beautiful nature-themed weather application built with Vue.js and Tailwind CSS.

## Features

- 🌿 Nature-inspired design with earthy colors
- 🌤️ Real-time weather data from OpenWeather API
- 📱 Responsive design
- 🔍 City search functionality
- 🌡️ Temperature, humidity, wind speed, and pressure display

## Setup

1. Install dependencies:
```bash
npm install
```

2. Get your free API key from [OpenWeather](https://openweathermap.org/api)

3. Create a `.env` file in the project root and add your API key:
```
VITE_OPENWEATHER_API_KEY=your_actual_api_key_here
```

4. Start the development server:
```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Technologies Used

- Vue.js 3
- Tailwind CSS
- Vite
- Axios
- OpenWeather API
